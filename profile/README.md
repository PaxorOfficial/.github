## Building the Paxor Ecosystem

Paxor is being developed as a unified Web3 platform where users can interact with blockchain networks, manage wallets and digital assets, explore music and NFT functionality, and use AI-powered tools from a single interface.

The ecosystem is under active development, with new functionality and public technical resources being added over time.

## Core Areas

- **Web3 Wallet** — wallet connectivity and blockchain asset management.
- **Blockchain** — tools for interacting with supported blockchain networks.
- **Transactions** — send, swap and other blockchain operations.
- **NFTs** — digital asset and NFT functionality.
- **Music** — music-focused tools and experiences within the Paxor ecosystem.
- **AI** — AI-powered functionality integrated into the platform.
- **Security** — Guardian protection, session monitoring, trusted addresses and WebAuthn passkeys for supported security-sensitive actions.
